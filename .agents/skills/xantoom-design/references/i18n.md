# Every language

Xantoom apps ship at least French and English, and the components must hold any language: right-to-left, CJK, and
scripts with tall glyphs or long words.

## Text

- The design system and the components contain no words. Every string, including `aria-label`s, toast close labels
  (`data-close-label`), placeholders and `alt` text, comes from the app's i18n catalogue.
- Format dates, numbers, currencies, lists and relative times with `Intl`, in the user's locale. Detect the language
  from `navigator.languages` and `Accept-Language`, never from the IP address.
- Expect text to be 30 to 50 % longer than English (German, French, Finnish), so let containers grow and wrap. Never
  give text a fixed width or height. Use `x-truncate` only where the full text is reachable another way.
- Keep brand names, product names and code out of machine translation with `translate="no"`. Use non-breaking spaces
  for units and shortcuts (`10&nbsp;MB`), and the right punctuation for the language (a space before `:` in French;
  `…`, `’`, `« »`).

## Direction

- Set `dir="rtl"` on `<html>` for Arabic, Hebrew, Persian and Urdu (or `dir="auto"` on user content).
- Use only logical properties: `margin-inline-start`, `padding-block`, `inset-inline-end`, `border-start-start-radius`,
  `text-align: start`. The tests reject physical ones. The only exceptions are things that must not flip, such as
  safe-area insets and `background-position`, which has no logical form (mirror it with `:dir(rtl)`).
- Directional icons (arrows, chevrons pointing to the next item, "back") get `x-flip-rtl`. Do not flip icons for real
  objects (a clock, a play button, a logo).
- Translations along the inline axis (switch thumb, side sheet) multiply by a `--_dir` that is `-1` under
  `:dir(rtl)`.
- Physical keys stay physical: in RTL, ArrowRight moves to the previous tab (`enhance()` handles this).

## Scripts

- `--x-leading` rises to 1.75 for Arabic, Hebrew, Indic, Thai, Lao, Khmer, Myanmar and Tibetan scripts, and to 1.7
  for Chinese, Japanese and Korean. Headings get `--x-leading-tight`.
- CJK text gets no negative letter spacing, uses strict line breaking and `text-autospace`, and Japanese uses
  `word-break: auto-phrase` (Chromium). Never put `letter-spacing` on CJK.
- Inter covers Latin, Greek and Cyrillic. Other scripts fall back to the system fonts (`system-ui`, Noto). Do not
  force a Latin font on them.
- Never uppercase with CSS in languages where it changes meaning or lacks case (`text-transform` only on Latin
  labels, and only for short labels).

## Check

Switch the demo to `dir="rtl"`, Arabic and Japanese, at 320 px and at 200 % zoom. Nothing may overlap, clip or point
the wrong way.
